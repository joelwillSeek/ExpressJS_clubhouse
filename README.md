<h1> Getting Started </h1>
<p>Clone the project </p>

```bash
git clone https://github.com/joelwillSeek/ExpressJS_clubhouse
```
<ul>
  <li>Npm</li>

```bash
npm install
```

<li>To configure if necessary in MongoDBConnection.ts</li>

```typescript
const uri=process.env.MONGODB_URI
```

<li>To run development</li>

```bash
npm run dev
```

<li>To build</li>

```bash
npm run build
```

<li>Hosted IN <a href="https://expressjs-clubhouse.onrender.com">Website</a></li>
</ul>
